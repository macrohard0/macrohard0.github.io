## 关于 Windows 11 版本

Windows 11 主要分为两个大版本：**消费者版（Consumer）** 和 **商业版（Business）**。

- **消费者版**：内含 家庭版、家庭单语言版、教育版、专业版、专业教育版、专业工作站版。
- **商业版**：内含 企业版、教育版、专业版、专业教育版、专业工作站版。

品牌机/笔记本重装系统，推荐选择家庭版，重装完成会自动激活正版系统（如果出厂自带正版 win10/11）。

下表列举了一些常见 ISO 镜像的信息，**除 XP 外，其他系统的 32 位版本未统计**。
